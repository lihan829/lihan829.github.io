# Resources

I enjoy building and sharing open computational tools, datasets, and code to support reproducible research in phonology and linguistic analysis.

## Softwares & Scripts

### [BUFIA-AR](https://github.com/lihan829/BUFIA_AR)
Implementation of the Bottom-Up Factor Inference Algorithm over autosegmental representations for learning tonal and phonotactic patterns from structured data.

- Tonotactic learning over autosegmental graphs
- Structured and interpretable representations
- Experimental comparison with probabilistic learners


### [SpeechSlides](https://github.com/lihan829/Speechslides)
A lightweight web toolkit for collecting speech data while presenting stimuli.

- Browser-based
- Displays stimuli in a randomized presentation
- Records speech directly in the browser
- Suitable for laboratory, fieldwork use, or participant self-recording


### [Hayes Feature Generator](https://colab.research.google.com/drive/19FSfDR90-3X3QvCi501vO1vOPYCzz9Cz?usp=drive_link)
Google Colab notebook for generating language-specific Hayes feature matrices from a phoneme inventory.

- Extract features from the Hayes feature chart
- Automatically generate nasal, long, and tonal vowel features
- Export feature matrices in a CSV file


### [Prosodic Extractor](https://github.com/lihan829/ARextractor)
A tool for extracting syllabic, segmental, and tonal structures from orthographic input and converting them into multi-tier representations.

- Automatic extraction of prosodic structure
- Multi-tier representation generation
- Configurable language-specific mappings
